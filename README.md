# Supply Chain & Logistics Analytics Dashboard

A multi-page Power BI dashboard analyzing supply chain performance, profitability, delivery delays, and financial impact using the DataCo Smart Supply Chain dataset.

## Dashboard Pages
1. Supply Chain Overview
2. Profit Leakage
3. Delivery Failures
4. Root Cause Analysis of Late Deliveries
5. Financial Impact and Action Plan

## Key Metrics
- Total Sales and Profit
- On-Time and Late Delivery Rates
- Loss-Making Orders
- Loss Exposure
- Recoverable Profit
- Late Order Reduction Targets
